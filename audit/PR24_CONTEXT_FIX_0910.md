# PR #24 후속 수정 — 공통 표현은 문맥과 함께 연결

2026-09-10 · Codex

## 결과

예은님의 외주 대금·복지·상속·교통사고·서식 검색 개선을 유지하면서, 추가 표현이 다른 분야의 질문을 가져가는 문제를 보완했다.

- 직급 단독 단서를 제거했다. 괴롭힘·폭언·따돌림 표현에 직장 단서가 함께 있어야 새 동의어를 적용한다.
- 통원치료·진단서 발급 같은 일반 치료 표현에는 교통사고 단서가 필요하다. 대인합의·자기신체사고 같은 전용 표현은 바로 연결한다.
- ‘저도 받을’, 부양·간병, 채무 규모 등의 일반 표현은 사망·상속 단서가 있어야 상속 절차에 연결한다.
- ‘계속 살고 싶다’, ‘2년 더’가 임대차로 연결되는 조건도 주거 문맥으로 한정했다.

선택 조건 `requiresAny`를 동의어 자료에 추가했다. 해당 조건이 없는 기존 항목의 처리 방식과 점수는 그대로다. 법령·판례·서식 본문은 바꾸지 않았다.

## 검증

| 실제 질문 | 수정 전 PR | 수정 후 |
|---|---|---|
| 상사가 성추행했어요 | 직장내괴롭힘 | 성폭력신고고소 |
| 상사가 육아휴직을 거부해요 | 직장내괴롭힘 | 육아휴직급여출산휴가급여 |
| 산재로 통원치료 받고 있어요 | 교통사고손해배상청구 | 산재요양급여신청 |
| 병원 의료사고로 통원치료 중입니다 | 교통사고손해배상청구 | 의료사고대응증거확보 |
| 저도 받을 수 있는 복지 지원이 있나요 | 상속재산분할협의 | 긴급복지지원 |

위 5개는 변경 전 main에서도 확인했던 경로다. 마지막 복지 질문은 여전히 추가 정보가 필요하므로 긴급복지지원이 개인에게 적합하다는 의미는 아니다.

- 전체 테스트 279개 통과: PR 기존 263개 + 추가 16개.
- 타입 검사·빌드 통과.
- 주제 279개 자가진단 및 외주대금 등 기존 테스트 유지.
- 일부 기존 테스트 문장은 교통사고·사망·상속 문맥을 명시하도록 수정했다. ‘통원치료’만으로 교통사고를, 살아 있는 가족의 재산·부양 질문만으로 상속을 정답으로 가정할 수 없기 때문이다. 모호한 문장에 대한 부정 검사도 함께 추가했다.
- 로컬 MCP HTTP 응답을 검증했다. 실제 카카오 LLM의 도구 호출 여부와 실기기 화면은 별도 확인 사항이다.

## 남은 과제 (이번 머지와 구분)

1. 위기 표현과 채무 절차 안내를 함께 제공하는 방식: 기존 보고서에 남긴 문제이며 이번 변경은 구현하지 않는다.
2. 대금 청구 주제와 기존 지급명령 서식 연결, 보정명령 등 콘텐츠 보강: 정확한 적용 범위와 원문 검증 필요.
3. 기존 검색의 부분문자열·상속포기 편중 등: 모든 자연어 표현의 정확성을 보장하지 않는다. 문맥이 불충분하면 검색 실패가 남을 수 있다.
4. 본선 서버 재배포 후 다섯 오류 문장과 외주대금 문장을 다시 확인한다. 예선 서버는 변경하지 않는다.

## 팀 공유 문안 (미발송)

예은님 PR 검토하고 후속 수정까지 마쳤습니다. 빠진 표현을 보완해주신 덕분에 외주 대금·복지·상속·교통사고와 서식 검색이 개선됐습니다.

추가 검사에서 ‘상사가 성추행했어요’가 직장 내 괴롭힘으로, ‘산재로 통원치료 받고 있어요’가 교통사고로 연결되는 등 5건을 발견했습니다. 여러 분야에서 쓰는 표현에는 해당 분야의 문맥이 함께 있어야 연결되도록 수정했습니다. 총 279개 검사와 빌드가 통과했습니다.
