# ccrs5500 카페 스크래퍼 — 작업 노트

## 목적

`cafe.naver.com/ccrs5500`(신용회복위원회 카페) 게시판에서 좋아요 많은 글을 게시판별로 상위 N개씩 수집.
목적은 **글 내용 자체를 저장/재배포**하는 게 아니라, `legal-navigator-mcp` 데이터(주제·동의어) 빈틈을 찾기 위한
**주제 빈도 신호**로만 씀 — 커뮤니티 회원 글은 저작권·declaw 원칙상 그대로 데이터에 넣지 않음
(자세한 배경은 세션 대화 참고, 결과물: `새출발기금` 주제 추가).

## 파일

- `collect_ccrs5500_top.py` — 스크래퍼 본체
- `naver_login_state.json` — Playwright 저장 로그인 세션 (⚠️ git 추적 안 함, `.gitignore` 등록됨)
- `ccrs5500_top_engagement.json` / `.html` — 실행 결과물 (⚠️ git 추적 안 함)

## 실행 방법

```bash
cd scripts
python collect_ccrs5500_top.py 30   # 게시판당 상위 몇 개 (기본 30)
```

최초 실행 시 `naver_login_state.json`이 없으면 브라우저가 뜨고 수동 로그인 후 Enter — 이후 세션 재사용.
Playwright(`pip install playwright` + `playwright install chromium`) 필요.

## 동작 원리

1. **카페 정보 자동 탐지** (`discover_cafe`) — 카페 메인 페이지 HTML에서 `clubid` 정규식 추출, 모든 iframe을 순회하며 `menuid` 붙은 링크로 게시판 목록 수집
2. **대상 게시판 필터** — `BOARD_KEYWORDS`(연체전·이자율·채무조정·개인회생·개인파산·채무관련 등)에 매칭되는 게시판만 대상
3. **좋아요순 정렬** — 자체 점수 계산(조회수+댓글수 가중치) 대신, 카페가 이미 제공하는 정렬 기능을 그대로 사용:
   `https://cafe.naver.com/f-e/cafes/{clubid}/menus/{menuid}?viewType=L&page={n}&sortBy=LIKE`
   (`ArticleListThead_btnSort` 버튼을 실제로 클릭해서 URL을 역추적해 알아냄)
4. **공지/필독 제외** — 목록 행이 글 번호 대신 "공지"/"필독" 라벨로 시작하면 운영진 고정글이라는 뜻이라 스킵
   (`row['rowText'].lstrip().startswith(row['articleId'])`)
5. **행 텍스트에서 통계 추출** (`parse_stats`) — DOM 클래스가 카페 스킨마다 달라 정확한 컬럼 매칭 대신 휴리스틱 사용:
   - 댓글수: `[숫자]` 패턴, 콤마 포함 가능(`[1,502]`)
   - 조회수/좋아요: 행 끝에서 숫자 2개(항상 "...날짜 조회수 좋아요" 순서로 끝남)
   - "5.8만" 같은 만 단위 표기는 실제 값으로 환산 후 숫자 추출

## 디버깅 중 잡은 버그 3개 (참고용)

같은 실수를 반복하지 않기 위한 기록:

1. 행 안의 "최댓값"을 조회수로 뽑았더니 글 번호(article_id, 대개 조회수보다 큼)가 찍힘 → 끝에서 두 번째 숫자로 변경
2. "5.8만" 같은 만 단위 표기를 숫자로 못 바꿔서 조회수가 깨짐 → `만` 단위 정규식 치환 추가
3. 댓글수 `[1,502]`처럼 콤마 있으면 `\d+`가 끊겨서 `1`만 읽힘 → `[\d,]+`로 수정 후 콤마 제거

## 알려진 한계

- 좋아요순 상위 글은 대부분 정보 정리·경험담 장문 글(오래전 작성) 위주로 쏠림 — "지금 당장 고민 중" 류의 즉흥 질문글은 좋아요가 적어 이 방식으로는 안 올라옴. 실시간 질문 트렌드가 필요하면 정렬 기준(최신순 + 댓글 급증)을 따로 설계해야 함
- 만 단위/콤마 파싱은 지금 카페 스킨 기준 휴리스틱 — 카페 UI가 바뀌면 `raw_row_text` 필드로 재확인 필요
- 각 게시판 최대 10페이지(`MAX_PAGES_PER_BOARD`)까지만 순회 — 좋아요순 정렬 안에서 상위 N개를 못 채우면 그 게시판은 N개 미만으로 나올 수 있음
